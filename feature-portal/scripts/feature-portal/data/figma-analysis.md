## 界面流程

- 运动入口
  - 进入左右手选择页 → Template ReadyGo【已确认：PFS】【待确认：设计推测】
  - 进入 ReadyGo【已确认：PFS】【待确认：设计推测】
- HSP 连接页
  - 连接完成 → ReadyGo【已确认：PFS】【待确认：设计推测】
  - 点击跳过 → ReadyGo【已确认：PFS】【待确认：设计推测】
- ReadyGo / Template ReadyGo
  - 点击 Go → 自动校准提示页【已确认：PFS】【已确认：原型】
  - 自动校准提示页 → 开始 10 秒倒计时【已确认：PFS】【待确认：设计推测】
  - 自动校准提示页 → 退出并返回 ReadyGo【已确认：PFS】【待确认：设计推测】
- 静态校准流程
  - 首次进入 → 佩戴提示页 → 校准确认页 → 开始校准【已确认：PFS】【待确认：设计推测】
  - 校准确认页 → 校准指导 / 佩戴提示页【已确认：PFS】【待确认：设计推测】
  - 校准成功 → 成功确认页 → ReadyGo / Template ReadyGo【已确认：PFS】【待确认：设计推测】
  - 校准失败 → 失败确认页 → 校准确认页【已确认：PFS】【待确认：设计推测】
- 跳过校准
  - 跳过校准 → 跳过确认页【已确认：PFS】【待确认：设计推测】
  - 点击“校准” → 开始校准【已确认：PFS】【待确认：设计推测】
  - 点击“继续跳过” → ReadyGo / Template ReadyGo【已确认：PFS】【待确认：设计推测】
- 运动中跑步阶段
  - 自动校准成功 → Toast + 震动提示【已确认：PFS】【待确认：设计推测】
  - 自动校准未成功 → 不提示【已确认：PFS】
- HSP 版本号确认
  - 版本号未确认 → 支持动态校准时进入动态校准，否则进入静态校准【已确认：PFS】

## 操作说明

1. 在运动入口，用户选择运动后进入左右手选择页或 ReadyGo；证据是 PFS，画布中存在 `Dialog - Select Wrist Side`，但未获取到对应原型连线。
2. 在 HSP 连接页，用户连接完成或点击跳过，进入 ReadyGo；证据是 PFS，画布中存在 `Dialog - Connecting`，具体跳转仅能由 PFS 确认。
3. 在 ReadyGo，用户点击 Go，进入自动校准提示页；证据是 PFS，画布中存在 `Dialog - Tips`，其中包含“设备将在运动中后台自动校准，请正确佩戴”的界面文字。
4. 在自动校准提示页，用户可开始 10 秒倒计时或退出返回 ReadyGo；证据是 PFS，具体按钮行为未获取原型跳转证据。
5. 在静态校准首次进入时，用户查看佩戴提示、确认校准并开始校准；证据是 PFS，以及画布中存在包含“Wear sensors and stay still for 10s”的佩戴提示内容。
6. 在校准确认页，用户可进入校准指导和佩戴提示页；证据是 PFS，未获取对应原型连线。
7. 校准成功后，用户进入成功确认页并返回 ReadyGo / Template ReadyGo；校准失败后进入失败确认页并返回校准确认页；证据是 PFS，未获取对应原型连线。
8. 运动开始后的跑步阶段，自动校准成功时显示 Toast 并震动；证据是 PFS，且运动数据界面存在 Toast 组件。自动校准未成功时不提示，仅由 PFS 确认。
9. 版本号未确认时，根据是否支持动态校准选择动态或静态校准；证据是 PFS，未获取版本号判断页的原型跳转证据。
