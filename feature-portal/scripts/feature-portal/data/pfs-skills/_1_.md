# PFS 需求

## 需求正文
1、新增运动入口至左右手选择页、Template ReadyGo页和ReadyGo页的流程覆盖
2、补充HSP连接完成、连接页跳过后进入ReadyGo页的流程
3、新增ReadyGo页点击Go后进入自动校准提示页，并支持开始10秒倒计时或退出返回ReadyGo页
4、新增运动中跑步阶段自动校准成功后的震动Toast提示
5、明确运动中自动校准失败时不显示提示
6、增加HSP版本号确认逻辑：版本号未确认动态校准时进入静态校准流程
7、新增静态校准首次进入时的佩戴提示页、校准确认页及校准指导流程
8、新增从校准确认页跳过校准后的跳过确认页，并支持点击校准或继续跳过
9、新增校准成功后进入成功确认页并返回ReadyGo/Template ReadyGo页的流程
10、新增校准失败后进入失败确认页并返回校准确认页的流程
11、明确佩戴提示页可由多种运动类型共用首次展示
12、保持校准成功/失败对运动中及运动记录的对齐逻辑不变
